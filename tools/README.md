## 4、cat1（FOTA）

1）功能支持：
- 为UE（User Equipment）生成FOTA（Firmware Over-The-Air）升级所用的升级包。通过串口发送升级包文件到对应的UE，进行近端（串口）升级。该工具适用于模块集成商和终端部署的管理者用来生成FOTA升级包，以升级其UE的Hi2131固件程序

2）使用参考：[HiDiTingV100 2131E FOTA升级包制作工具 用户指南](../docs/docs-zh_CN/HiDiTingV100/tools/HiDiTingV100%202131E%20FOTA升级包制作工具%20用户指南/HiDiTingV100%202131E%20FOTA升级包制作工具%20用户指南.md)
